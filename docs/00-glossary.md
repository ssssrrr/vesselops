## 1. 선박 일반

| 용어 | 영문/원어 | 설명 |
|---|---|---|
| **IMO 번호** | IMO Number | 선박에 부여되는 7자리 국제 고유 식별번호. 선명이나 선적이 바뀌어도 변하지 않아 선박 식별의 기본키로 사용한다 |
| **선급** | Classification Society | 선박의 구조·설비가 기준에 맞는지 검사·증서를 발급하는 기관. 한국선급(KR), DNV, Lloyd's Register(LR), ABS, NK 등 |
| **동형선** | Sister Ship | 같은 설계로 건조된 선박. 성능 비교의 기준이 된다. 같은 조건에서 연비 차이가 나면 한 척에 문제가 있다는 뜻이다 |
| **재화중량톤수** | DWT, Deadweight Tonnage | 선박이 실을 수 있는 화물·연료·청수 등의 총 중량 |
| **운항 중단** | Off-hire | 고장 등으로 선박이 운항하지 못하는 상태. 용선료를 받지 못해 손실이 직접 발생한다 |
| **감속 운항** | Slow Steaming | 연료 절감을 위해 설계 속도보다 낮은 부하로 운항하는 방식 |
| **입출항 조종** | Manoeuvring | 항구 진입·이탈 시 저부하·빈번한 출력 변경이 이루어지는 운전 상태 |

## 2. 기관(엔진) 용어

| 용어 | 영문/원어 | 설명 |
|---|---|---|
| **주기관** | ME, Main Engine | 선박을 추진하는 주 엔진. 대형 선박은 저속 2행정 디젤기관을 쓴다 |
| **발전기관** | DG, Diesel Generator | 선내 전력을 생산하는 보조 엔진. 통상 2~4대를 두고 부하에 따라 대수를 조절한다 |
| **과급기** | TC, Turbocharger | 배기가스로 터빈을 돌려 흡입 공기를 압축해 밀어넣는 장치. 같은 배기량에서 더 많은 연료를 태울 수 있게 한다 |
| **소기** | Scavenge Air | 과급기가 압축해 실린더로 보내는 공기. 압력·온도가 연소 품질을 좌우한다 |
| **실린더냉각수** | JCW, Jacket Cooling Water | 실린더 벽을 식히는 냉각수. 입·출구 온도차가 기관이 내는 열량을 반영한다 |
| **윤활유** | LO, Lubricating Oil | 기관 각부를 윤활하는 오일. **압력 저하는 즉시 기관 손상으로 이어져 최우선 감시 대상**이다 |
| **연료유** | FO, Fuel Oil | 선박 연료. 중유는 점도가 높아 가열해야 분사되므로 온도 관리가 필요하다 |
| **추력베어링** | Thrust Bearing | 프로펠러가 만든 추진력을 선체로 전달하는 베어링. 온도 상승은 축계 이상의 신호다 |
| **정격출력** | MCR, Maximum Continuous Rating | 기관이 연속으로 낼 수 있는 최대 출력. 부하율은 이 값에 대한 비율이다 |
| **모델 표기 예** | 7S60ME-C10.5 | 7=실린더 수, S=초장행정, 60=실린더 내경 600mm, ME=전자제어 |

## 3. 계측·진단 용어

| 용어 | 영문/원어 | 설명 |
|---|---|---|
| **상태기반 정비** | CBM, Condition Based Maintenance | 운전시간이 아니라 **실제 상태**를 근거로 정비 시점을 정하는 방식. 본 시스템의 목표 |
| **계획 정비** | PMS, Planned Maintenance System | 운전시간·주기에 따라 일률적으로 정비하는 기존 방식 |
| **연료소비율** | SFOC, Specific Fuel Oil Consumption | 1kWh 를 내는 데 쓰는 연료량(g/kWh). 기관 효율의 핵심 지표. 부하 75% 부근이 최적이고 그보다 낮거나 높으면 나빠지는 U자 곡선을 그린다 |
| **배기온도 편차** | Exhaust Temperature Deviation | 각 실린더 배기온도와 전 실린더 평균의 차이. **절대값이 정상 범위여도 편차가 크면 이상**이다. 연료분사밸브 불량·배기밸브 누설의 조기 징후 |
| **진동 실효값** | Vibration RMS | 진동 크기의 실효값(mm/s). ISO 10816 이 설비 등급별 허용 구간(Zone A~D)을 정한다 |
| **채터링** | Chattering | 계측값이 경보 임계값 부근에서 흔들려 경보가 반복 발생·해제되는 현상 |
| **지속시간 조건** | Dwell | 채터링을 막기 위해 "조건이 N초 이상 지속될 때만 경보를 확정"하는 설정 |
| **경보 등급** | HI / HIHI / LO / LOLO | 상한 경보·상한 위험·하한 경보·하한 위험의 4단계 |
| **경보 확인** | Acknowledge (Ack) | 운전자가 경보를 인지했음을 기록하는 조작. 경보 해제와는 다르다 |

## 4. 자동화·통신 용어

| 용어 | 영문/원어 | 설명 |
|---|---|---|
| **기관 자동화 시스템** | AMS / IAS | 기관실 전체의 계측값을 수집하고 경보를 관리하는 시스템. **선박 데이터의 1차 집결지**. Kongsberg, Wärtsilä 등이 공급한다 |
| **엔진 제어 시스템** | ECS | 전자제어 기관의 연료분사·배기밸브 타이밍을 제어하는 시스템. MAN ME-ECS, WinGD WECS 등 |
| **OPC UA** | IEC 62541 | 산업 설비와 상위 시스템을 잇는 국제 표준 통신 규격. 태그 탐색, 인증·암호화, 읽기전용 권한이 규격에 포함되어 있다 |
| **NodeId** | — | OPC UA 서버 안에서 특정 계측점을 가리키는 주소. 예: `ns=1;s=IMO9876543.ME.ME_RPM`. **서버마다 형식이 달라 현장 확인이 필수**다 |
| **주소공간** | Address Space | OPC UA 서버가 노출하는 노드들의 계층 구조 |
| **품질코드** | StatusCode / Quality | 계측값의 신뢰도. Good(192) / Uncertain / Bad 로 구분한다. 값과 함께 저장해야 한다 |
| **구독** | Subscription | 값이 변할 때만 서버가 알려주는 OPC UA 방식. 주기 폴링보다 효율적이다 |
| **MQTT** | — | 저대역·불안정 회선에 적합한 경량 메시징 규격. 선박-육상 구간의 사실상 표준 |
| **QoS 1** | Quality of Service 1 | MQTT 전송 보증 수준. "최소 1회 도달"을 보장하므로 중복이 발생할 수 있다 |
| **Deadband** | 불감대 | 변화량이 설정값보다 작으면 전송하지 않는 필터. **위성통신 대역·비용 절감의 핵심 수단** |
| **Store-and-Forward** | 저장 후 전송 | 통신 단절 시 로컬에 쌓아두었다가 복구되면 전송하는 방식 |
| **Edge 수집기** | Edge Gateway | 현장(본선)에 설치되어 설비 데이터를 수집·가공·전송하는 장치 또는 프로그램 |
| **KEPServerEX** | — | 이기종 PLC 프로토콜을 OPC UA 등으로 변환해주는 상용 미들웨어. 변환 대상이 없으면 불필요하다 |
| **UaExpert** | — | OPC UA 서버에 접속해 주소공간을 탐색·진단하는 **클라이언트 도구**. 개발·시운전 단계에서 NodeId 확인에 사용한다 |

## 5. 시스템·개발 용어

| 용어 | 영문/원어 | 설명 |
|---|---|---|
| **텔레메트리** | Telemetry | 원격지 설비에서 수집해 전송하는 계측 데이터 |
| **계측점 / 태그** | Tag / Point | 개별 측정 항목 하나. 예: "3번 실린더 배기온도" |
| **시계열 데이터베이스** | TSDB | 시간축 데이터에 최적화된 DB |
| **Hypertable** | — | TimescaleDB 가 시간 기준으로 자동 분할 관리하는 테이블. 사용자에게는 일반 테이블로 보인다 |
| **연속 집계** | Continuous Aggregate | 원본이 쌓이는 동안 1분·1시간 평균을 자동 갱신해두는 기능. 장기간 조회 성능을 확보한다 |
| **다운샘플링** | Downsampling | 오래된 데이터를 평균값으로 줄여 저장량과 조회 비용을 낮추는 것 |
| **보존 정책** | Retention Policy | 일정 기간이 지난 데이터를 자동 삭제하는 설정 |
| **JWT** | JSON Web Token | 로그인 후 발급되는 서명된 토큰. 서버가 세션을 보관하지 않아도 된다 |
| **행 수준 제한** | Row-level Restriction | 같은 화면이라도 사용자에 따라 보이는 행을 제한하는 것. 본 시스템에서는 기관사가 자선 데이터만 보게 한다 |
| **ADR** | Architecture Decision Record | 설계 결정과 그 근거, 버린 대안을 기록하는 문서 형식 |
| **RTM** | Requirements Traceability Matrix | 요구사항이 설계·구현·테스트로 이어졌는지 추적하는 표 |

## 6. 규정·기관

| 용어 | 설명 |
|---|---|
| **IMO** | 국제해사기구. 선박 안전·환경 관련 국제 규정을 제정한다 |
| **SOLAS** | 해상인명안전협약. 기관 제어 계통이 이 규정의 적용을 받는다 |
| **IACS** | 국제선급연합회 |
| **IACS UR E26 / E27** | 선박 사이버보안 통일규칙. 2024년 7월 이후 계약된 신조선에 적용되며, 선박 시스템에 외부 장비를 연결할 때 적용 대상이 된다 |
| **CII** | 탄소집약도지수. 선박의 연간 운항 대비 이산화탄소 배출을 등급화하는 IMO 규제 지표 |
| **EEXI** | 현존선 에너지효율지수. 기존 선박의 설계 효율을 규제하는 지표 |
| **IEC 62541** | OPC UA 의 국제표준 번호 |
| **ISO 10816** | 기계 진동 평가 기준. 설비 등급별 허용 진동 구간을 규정한다 |
